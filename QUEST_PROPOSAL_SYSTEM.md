# Quest Proposal System

## Огляд

Система пропозиції квестів створює інтерактивний "pre-quest loop", де гравці можуть взаємодіяти з пропозиціями квестів перед прийняттям рішення. Це додає драматизму та глибини в ігровий процес.

## Основні функції

### 🎯 Пропозиція квесту
- **Квестодавець**: Різні персонажі з унікальними іменами та фракціями
- **Вступ**: Короткий сюжетний вступ від квестодавця
- **Опис завдання**: Детальний опис того, що потрібно зробити
- **Нагороди**: Золото та досвід, залежно від рівня ризику
- **Рівень ризику**: 1-5, впливає на нагороди та наслідки

### 🟡 Дія "Розпитати"
- Гравець може **один раз** запитати додаткову інформацію
- Відкриває передісторію, потенційні нагороди, ризики
- Може містити підказки про те, що чекає попереду
- Після використання кнопка зникає з меню

### 🟢 Прийняти квест
- Запускає генерацію подій квесту
- Зберігає дані про квест в базі даних
- Переводить гравця в стан активного квесту
- В майбутньому можна додати систему репутації

### 🔴 Відмовити від квесту
- Викликає подію, а не просто "шукати новий квест"
- Різні варіанти наслідків:
  - **Образа**: Квестодавець ображається (мінус репутація)
  - **Наполегливість**: Дає інший, легший/важливіший варіант
  - **Попередження**: Попереджає про небезпеку, що може запустити зустріч


### Моделі даних

#### QuestProposal
```python
class QuestProposal(Base):
    user_id: int
    questgiver_name: str
    quest_intro: str
    quest_description: str
    additional_info: str
    faction: str
    reward_gold: int
    reward_xp: int
    risk_level: int
    info_asked: bool
    status: str  # pending, accepted, refused
```

#### PlayerReputation
```python
class PlayerReputation(Base):
    user_id: int
    faction: str
    reputation: int  # -100 to 100
```

### Обробники

#### `/quest` команда
1. Генерує пропозицію квесту з випадковим квестодавцем
2. Створює запис в базі даних
3. Показує інтерактивне меню з опціями
4. Переводить в стан `QUEST_PROPOSAL`

#### Callback обробники
- `quest_ask_info`: Обробляє запит додаткової інформації
- `quest_accept`: Обробляє прийняття квесту
- `quest_refuse`: Обробляє відмову від квесту

## Фракції та репутація

### Доступні фракції
- **Маги Ордену**: Магічні завдання, високі нагороди
- **Королівська Гвардія**: Офіційні завдання, стабільні нагороди
- **Гільдія Мисливців**: Завдання на виживання, природні нагороди
- **Темне Братство**: Небезпечні завдання, великі нагороди
- **Коло Друїдів**: Природні завдання, екологічні нагороди
- **Гільдія Ремісників**: Технічні завдання, матеріальні нагороди

### Рівні репутації
- **Exalted** (80-100): Найвищі нагороди, ексклюзивні завдання
- **Honored** (60-79): Високі нагороди, складні завдання
- **Friendly** (40-59): Хороші нагороди, стандартні завдання
- **Neutral** (20-39): Базові нагороди, прості завдання
- **Unfriendly** (0-19): Знижені нагороди, обмежений вибір
- **Hostile** (-40 до -1): Мінімальні нагороди, ворожі завдання
- **Hated** (-100 до -41): Відмова в завданнях, ворожість

## Майбутні покращення

1. **Система репутації**: Повна інтеграція з ігровим процесом
2. **Динамічні наслідки**: Більше варіантів реакцій на відмову
3. **Квестодавці з історією**: Персонажі з власною біографією
4. **Умовні завдання**: Завдання, що залежать від репутації
5. **Групові завдання**: Можливість спільної роботи з іншими гравцями
6. **Часові завдання**: Завдання з обмеженим часом виконання
